# 玩法设计 — 《坍缩点》

## 一句话钩子

一个没有子弹的射击游戏，你的武器是一颗可以随时创造、又能瞬间关闭的可抛掷微型黑洞。

## 核心循环

**创造 → 吸入 → 爆发**

玩家控制一个角色（Demo 采用第三人称），无法使用任何传统武器。唯一战斗/解谜交互是向场景中发射一个「奇点」。

## 操作

| 输入 | 行为 |
|------|------|
| 按住右键 | 在瞄准位置生成可见的重力奇点 |
| 持续按住 | 奇点引力指数级增长，吸入周围物理对象、敌人、场景碎片 |
| 松开右键 | 奇点瞬间崩塌；被吸物体带着巨大动量沿切线方向甩出 |
| 左键 | 轻推 / 弹跳（自身位移或微调物体方向） |

操作刻意极简：学会三步即可上手，深度来自物理与甩动技巧。

## 关键物理规则

1. **质量反馈**  
   吸入物体会增加奇点「质量」。质量越大，吸引范围越广，崩塌时抛射速度越高。

2. **能量时限**  
   奇点有能量上限（推荐维持约 **2.5 秒**）。超时自动崩塌，迫使快节奏决策。

3. **甩动瞄准**  
   崩塌抛射方向基于物体当时的旋转速度与位置做随机散射。若在松开前快速甩动鼠标，为所有物体附加一个方向性额外速度——提供「大致瞄准」的技巧上限。

## 为什么能成为亮点（亮点三问）

- **听完就手痒**  
  「用垃圾桶砸死敌人」「把一群敌人吸成一团再炸开」——物理交互的戏剧性远超预设动画。

- **白模就好玩**  
  用立方体与胶囊体搭一个房间、扔几个敌人 AI，机制本身就能玩很久；玩家会自发尝试「先吸天花板的灯再砸向地面」。

- **失败全是我的错**  
  没砸中是因为奇点位置偏了，或提前松手导致抛射角差。立刻想「下把这样调」，而不是怪系统。

## 记忆颗粒（Demo 必须有的三个瞬间）

### 第 5 秒 — 视觉钩子

奇点开启时，屏幕边缘出现轻微色散与扭曲（后处理 + 径向模糊），可动物体开始颤抖、向中心滑动，像龙卷风前夕。无 UI 说明，直觉即知「那个点在吸东西」。

### 第 30 秒 — 「哇时刻」

关卡中预设由数十个小立方体组成的「杂物堆」。第一次在此开启奇点：碎片被无形的手攥住、悬空旋转，松手瞬间轰然炸开，砸碎玻璃、撞倒敌人——无脚本的物理连锁是 Demo 的核心吸引力。

### 第 2 分钟 — 可触及深度

学会用杂物砸敌人后，立刻出现无法被小碎片伤害的重型敌人；地上放红色爆炸桶。玩家自然想到「吸桶砸它」。随后远处开关需高速抛射命中才能开门——迫使学会「蓄质量 + 甩动释放」。

## 单人友好设计约束

- **无角色动画依赖**：动态来自物理，省去最大工作量。  
- **无复杂 AI**：敌人只是走向玩家；戏剧性来自黑洞。  
- **内容高复用**：同样几个方块与敌人，靠物理交互产生不同场面。  
- **易传播**：物理混乱场面适合短视频。
