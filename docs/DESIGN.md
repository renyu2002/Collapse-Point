# 玩法设计 — 《坍缩点》

## 一句话钩子

往空中放一口引力井：质量绕它成环，滚轮塑形，Shift + 滚轮把水平环立起来穿缝；井不能穿过红色抑制场，但松手甩出的物体可以。不是传送门，也不是手里捏方块。

## 核心循环

**选物 → 入轨 → 塑形 → 拖刮 / 破坏 / 越场抛射 → 开门**

Demo 学《传送门 2》的试验腔写法（一腔一课、出口可见、失败重置），身份是可塑形轨道 + 质量选择 + 可破坏场景。无清怪过关。

## 操作

| 输入 | 行为 |
|------|------|
| 空格 | 跳跃 |
| 按住左键 | 在准星生成引力井；范围内物体入轨（不吞噬） |
| 拖动（按住） | 整口井平移，环刮压板、砸玻璃 |
| 滚轮（按住） | 在 80–380 cm 间收缩 / 扩张轨道 |
| Shift + 滚轮（按住） | 以 15° 步进在水平环与竖直环之间旋转轨道平面 |
| 松开左键 | 环沿准星甩出（瞄准丢） |
| 切向释放（待接入输入，暂由自动化驱动） | 沿轨道切线甩出，方向由松手相位决定（弹弓） |
| 过喂 + 过载器 | 井被强制引爆，质量径向喷发（级联坍缩） |
| 按住约 12s | 超时吞掉环上物体（丢工具）；本腔重置 |
| R | 重置当前试验腔关键物 |

## 关键物理规则

1. **轨道塑形**
   收缩环可让物体穿窄孔并集中冲击；扩张环可扫到相隔很远的开关；旋转轨道平面可让环从横向占宽切换为纵向占高。轻物绕得快，重物较慢但撞击强。

2. **引力点在场**
   物体先被拉向井再进入稳定轨道。环半径随质量略增。玩家受轻吸引，贴脸开井会干扰站位。

3. **抑制场分割“拖”和“甩”**
   红色抑制场阻止引力井生成或拖过边界，但玩家和脱离引力井的物体能穿过。脉冲场会按固定节拍开闭，要求观察窗口运输；常亮场要求在边界前松手完成越场抛射。

4. **可破坏是解谜动词**
   玻璃墙、吊物、脆板由环刮或甩出的物体击碎；引力井本身不能隔墙取物。碎了才露出方块或通路。过关不要求杀怪，但指定障碍必须破坏。

5. **质量选择与饥荒**
   轻碎块适合多点触发；重物才能驱动质量接收器。每腔物体数量固定。超时吞噬 = 消融格栅。R / 死亡 / 超时后重置本腔，不无限刷物。

6. **准星甩出**
   松手主方向 = 准星。甩动只加力。被甩出的物体可以穿过抑制场。

7. **易碎货物**
   青色易碎物可被稳定轨道搬运，但高速撞墙或抛射会损坏；它把“越快越好”改成速度、路线与窗口管理。

8. **坍缩门（"喂饱"即钥匙）**
   紫色质量门只在附近的引力井吞入足够质量、坍缩成黑洞时开启。前面所有腔都在教"别喂太多"，这里把同一条规则翻面：**故意**把井养成黑洞才是唯一解法。回看时理所当然——超时吞噬不再是惩罚，而是一把钥匙。

9. **反向收容场（"场"是你唯一的工作台）**
   青色反向收容场把规则反转：引力井**只能**待在场内，任何把井拖出边界的尝试都被挡住。前面红场教"井进不去"，这里教"井只能在这儿干活"——被困住的井仍能把货物甩出场外完成运输。

10. **切向弹弓（环本身就是发射台）**
   常规松手是"朝准星丢"（阻尼掉轨道速度、汇聚到准星方向）。切向释放则**保留并放大物体当下的轨道速度**，沿切线方向甩出——方向由松手**时机/相位**决定，而不是准星。井不再是"手里的容器"，而是一台能把动量甩出去的机器。准星丢不到的侧向目标，靠环的自转甩过去。

11. **级联坍缩喷发（喂饱会炸，炸能点燃下一台）**
   井吃到足够质量后由关卡上的"过载器"强制引爆：所有环上质量**沿径向四散喷发**。一次坍缩变成全向发射，能同时点亮四周一圈接收器——任何单次瞄准都做不到的事。喷出的质量还能去喂/点燃下一口井，形成连锁。"喂太多"从惩罚，进一步变成引擎。

## 为什么能成为亮点

- 工具是空间里的井，不是枪、不是传送门。
- 同一批物体有三种空间状态：窄环运输、宽环扫击、脱环抛射。
- 白模几何就能教：凹槽压板、窄孔、红色抑制面、轻重质量接收器。
- 失败是自己按太久或没先破障，立刻重置再试。

## 十三腔教学

| 腔 | 课 | 过关 |
|----|----|------|
| A | 井能拿物、能刮；玻璃会碎（预热） | 拖环刮凹槽压板开门 |
| B | 轨道可塑形 | 两轻物缩环穿孔，到出口前扩环打双开关 |
| C | 质量有分工 | 轻物破开重物仓，重物驱动质量接收器 |
| D | 拖不过就甩 | 在抑制场前松手，把物体甩过红场撞开门 |
| E | 综合 | 取两重物，缩环穿孔，再扩环同步关闭终点护盾 |
| F | 轨道不只会变大小 | 把水平环旋成竖环，携物穿过纵向窄缝 |
| G | 时机与完整性 | 等脉冲场熄灭，稳定搬运易碎货物开门 |
| H | 编舞终考（第一幕） | 选重物、缩环、立环穿缝，再越过常亮抑制场抛入质量接收器 |
| I | 喂饱即钥匙（翻面之一） | 故意把井养成黑洞，触发坍缩门 |
| J | 场是工作台（翻面之二） | 井被反向收容场困住，把货物甩出场外落到接收台 |
| K | 双动词终考 | 困在收容场内聚拢散落质量成黑洞，开坍缩门 |
| L | 环是发射台（我们自己的路之一） | 准星丢不到侧壁；靠切向弹弓把货物甩向侧墙接收器 |
| M | 级联坍缩（我们自己的路之二） | 过喂中央质量堆引爆，径向喷发同时点亮一圈接收器 |

记忆颗粒：B 的“收—过—放”、C 的轻重分工、D 的红场越界抛射、F 的“横环立起来”、G 的脉冲窗口、H 的连续编舞、I 的“喂饱是钥匙”、J 的“困住也能干活”、K 的双翻面合流、**L 的“环即弹弓”、M 的“坍缩即发射”**。

### 设计意图：两条路，一个"惊喜"内核

我们不照搬纪念碑谷的视觉悖论，而是让惊喜从**这套引力物理本身涌现**——玩家不是被骗，而是突然看懂"井是一台会自己演化、会发射质量的机器"。

**路线一：翻面（I/J/K）** —— 不加新输入，把已教规则反转语义：
- **喂太多是惩罚 → 喂太多是解法**（坍缩门）
- **场把井挡在外 → 场把井锁在内**（反向收容）

**路线二：井是机器（L/M）** —— 同一口井，暴露"发射"这一新面：
- **松手=朝准星丢 → 松手时机=沿切线甩**（切向弹弓）
- **坍缩=终点 → 坍缩=全向发射，可连锁**（级联喷发）

两条路共享同一内核：同一套动词、同一批白模，靠**物理必然**制造"啊哈"，回看却觉得规则一直如此。
