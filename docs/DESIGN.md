# 玩法设计 — 《坍缩点》

## 一句话钩子

一个没有子弹的射击游戏，你的武器是一颗可以随时创造、又能瞬间关闭的可抛掷微型黑洞。

## 核心循环

**创造 → 吸入 → 爆发**

玩家控制一个角色（Demo 采用第三人称），无法使用任何传统武器。唯一战斗/解谜交互是向场景中发射一个「奇点」。

## 操作

| 输入 | 行为 |
|------|------|
| 按住右键 | 在瞄准位置生成可见的重力奇点 |
| 持续按住 | 奇点引力指数级增长；**奇点随准星缓慢拖动**；吸入周围物理对象、敌人、场景碎片 |
| 松开右键 | 奇点瞬间崩塌；被吸物体带着巨大动量甩出（主方向见下） |
| 左键 | **短距自身弹跳 / 反冲**（位移工具；不负责瞄准射击） |

操作刻意极简：一个主动词（奇点）+ 一个位移辅键。深度来自拖动、蓄质量与松手瞄准。

## 关键物理规则

1. **质量反馈**  
   吸入物体会增加奇点「质量」。质量越大，吸引范围越广，崩塌时抛射速度越高。场景可吸质量有限时产生「挑食」决策（见手感支柱）。

2. **能量时限**  
   奇点有能量上限（推荐维持约 **2.5 秒**）。超时自动崩塌。崩塌后有短暂冷却（约 **0.3 s**）才能再次开启。

3. **瞄准：准星为主，甩动为加力**  
   崩塌主方向 = 松手瞬间的**准星/视线方向**。短窗口内的鼠标甩动提供**附加速率**（更狠，不改主方向）。随机锥角仅作小幅手感噪声（约 ±8–15°），保证「没砸中是我的错」。

4. **玩家也在物理闭环内**  
   玩家受奇点**轻吸引**（位移干扰，不可被吸进奇点销毁）。贴脸崩塌或被自抛碎片高速击中会受伤。崩塌反冲 + 左键弹跳支持「黑洞冲浪」位移。

## 为什么能成为亮点（亮点三问）

- **听完就手痒**  
  「用垃圾桶砸死敌人」「把一群敌人吸成一团再炸开」——物理交互的戏剧性远超预设动画。

- **白模就好玩**  
  用立方体与胶囊体搭一个房间、扔几个敌人 AI，机制本身就能玩很久；玩家会自发尝试「先吸天花板的灯再砸向地面」。

- **失败全是我的错**  
  没砸中是因为奇点位置偏了，或提前松手导致抛射角差。立刻想「下把这样调」，而不是怪系统。

## 记忆颗粒（Demo 必须有的三个瞬间）

### 第 5 秒 — 视觉钩子

奇点开启时，屏幕边缘出现轻微色散与扭曲（后处理 + 径向模糊），可动物体开始颤抖、向中心滑动，像龙卷风前夕。无 UI 说明，直觉即知「那个点在吸东西」。

### 第 30 秒 — 「哇时刻」

关卡中预设由数十个小立方体组成的「杂物堆」。第一次在此开启奇点：碎片被无形的手攥住、悬空旋转，松手瞬间轰然炸开，砸碎玻璃、撞倒敌人——无脚本的物理连锁是 Demo 的核心吸引力。

### 第 2 分钟 — 可触及深度

学会用杂物砸敌人后，立刻出现无法被小碎片伤害的重型敌人；地上放红色爆炸桶。玩家自然想到「吸桶砸它」。随后远处开关需高速抛射命中才能开门——迫使学会「蓄质量 + 甩动释放」。

## 手感支柱（Demo 必须守住）

1. **拖动奇点**  
   按住期间奇点跟着准星缓慢平移，不是「原地地雷」。手感从放陷阱变成「用无形的手捞东西」。

2. **准星决定方向，甩动决定力度**  
   易学、可追责；随机只做噪声，不做主因。

3. **风险对称**  
   奇点伤敌也能伤己、能推自己。武器同时是环境危险与位移工具。

4. **质量饥荒**  
   好弹药（重球、爆炸桶）稀缺，废料充足。逼玩家选择吸什么、何时崩塌。

5. **一种可读敌人差异即可**  
   Demo 最多一种特殊规则（例如重甲只吃侧面/背后高速撞击，或被吸时护盾短暂失效）。不堆状态机。

## 待验证假设（打磨阶段用白模证伪）

| ID | 假设 | 若证伪则… |
|----|------|-----------|
| H1 | 拖动奇点比定点生成更好玩，且不增加操作负担 | 退回定点，把深度留给甩动与蓄质量 |
| H2 | 0.3s 冷却足够防连点刷，又不破坏节奏 | 调到 0.15–0.5s 区间再测 |
| H3 | 轻吸引 + 贴脸风险让人紧张而不是烦 | 减弱自伤，保留轻位移干扰 |
| H4 | 左键只做位移时，玩家不会觉得「缺射击键」 | 给左键「微调飞行中物体」的极弱冲量 |
| H5 | C 区短同步窗口（非同一帧）可在 1–3 次尝试内学会 | 失败两次后放宽窗口或重摆重物位置 |
| H6 | A 区入口 10 秒内一次小连锁（碎玻璃/吊灯）能预热 30s 哇时刻 | 去掉预热，把预算全给杂物堆 |

## 明确不加（防稀释）

- 多种奇点类型 / 元素 / 升级树  
- 双奇点、时间暂停  
- 重剧情与教程弹窗  

## 单人友好设计约束

- **无角色动画依赖**：动态来自物理，省去最大工作量。  
- **无复杂 AI**：敌人只是走向玩家；戏剧性来自黑洞。  
- **内容高复用**：同样几个方块与敌人，靠物理交互产生不同场面。  
- **易传播**：物理混乱场面适合短视频。
