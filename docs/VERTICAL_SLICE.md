# Demo 垂直切片 — 引力点试验腔

单一连续白模关卡，十三间试验腔。无菜单、无剧情、无敌人清场。启动即 A 腔。结构学《传送门 2》，机制是引力井 + 可塑形轨道 + 可破坏。A–H 建立并组合动词，I–K 把已教规则"翻面"，L–M 揭开"井是一台会发射质量的机器"这一面——两条路都用物理必然制造惊喜，不照搬他人。

```
[ A：井是手 ] → [ B：收放 ] → [ C：轻重 ] → [ D：越场 ] → [ E：综合 ]
       → [ F：立环 ] → [ G：脉冲运输 ] → [ H：编舞终考 ]
       → [ I：喂饱即钥匙 ] → [ J：场是工作台 ] → [ K：双动词终考 ]
       → [ L：切向弹弓 ] → [ M：级联喷发 ] → 出口
```

## 全局约束

- 出口始终可见（门 / 蓝护盾在视线尽头），无教程 UI。
- 一腔一课；失败（掉坑、超时吞物）重置本腔关键物。
- R 重置当前腔，不刷无限方块。
- 按住左键时滚轮调整轨道半径：向内收缩便于运输，向外扩张便于多点扫击。
- 按住左键时 Shift + 滚轮旋转轨道平面：水平环逐步变成竖直环。
- 不做美术、音乐、Niagara。

---

## A 腔：井是手

### 空间

- 地上 1–2 块可吸方块。
- 红压板藏在凹槽：人走不到，环半径够刮到。
- 侧面预热玻璃；天花板一盏吊物，井拉会掉。
- 关闭的门通往 B。

### 教学

瞄准放井 → 方块入轨跟着井走 → 拖环刮压板开门。擦玻璃会碎。

### 验收

| ID | 标准 |
|----|------|
| A1 | 按住左键在准星生成井，方块被拉入环且不消失 |
| A2 | 按住时可拖井；环跟着走 |
| A3 | 不松手甩，仅拖环刮压板即可开门 |
| A4 | 空手碰不到压板、不能直接开门 |
| A5 | 环擦过预热玻璃会碎 |
| A6 | 贴脸开井有轻吸引 |

## B 腔：收—过—放

### 空间

- 两个轻物位于入口侧。
- 中央隔墙只留窄孔，默认宽度的轨道无法通过。
- 出口护盾有两个分离开关，小环够不到两侧。

### 教学

两轻物入轨 → 滚轮收缩 → 穿过窄孔 → 滚轮扩张 → 同步刮到左右开关。

### 验收

| ID | 标准 |
|----|------|
| B1 | 默认 / 宽环会被孔壁挡住 |
| B2 | 收缩到窄环后两轻物可通过 |
| B3 | 窄环无法同时覆盖左右开关 |
| B4 | 穿孔后扩环可同步关闭护盾 |
| B5 | 超时或 R 后本腔可解，不软锁 |

---

## C 腔：轻重分工

### 空间

- 入口有三块轻碎块。
- 重物在脆板仓后。
- 出口质量接收器只接受重物。

### 教学

用快速轻物刮 / 砸碎脆板 → 释放重物 → 重物入轨 → 驱动质量接收器。

### 验收

| ID | 标准 |
|----|------|
| C1 | 脆板破坏前拿不到重物 |
| C2 | 轻物可破障，但不能启动质量接收器 |
| C3 | 重物拖刮或撞击接收器后门开启 |
| C4 | 失败重置重物与挡板，不软锁 |

---

## D 腔：拖不过就甩

### 空间

- 红色抑制场横切房间。
- 场前有一块轻物，场后有撞击接收器。
- 玩家和脱离轨道的物体可过场，引力井不可过场。

### 教学

场前取物 → 瞄准场后接收器 → 在红场前松手 → 物体脱环穿场并撞开门。

### 验收

| ID | 标准 |
|----|------|
| D1 | 无法在红场内生成引力井 |
| D2 | 无法把已有引力井拖过红场 |
| D3 | 玩家可自由穿过红场 |
| D4 | 松手后的物体可穿场并触发接收器 |

---

## E 腔：综合终局

### 空间

- 一块重物可直接取得，第二块藏在脆板仓后。
- 中央再次出现窄孔。
- 尽头为只接受重物的双开关护盾。

### 教学

用第一重物破仓 → 两重物入同一轨道 → 缩环穿孔 → 扩环同步扫过终点双开关。

### 验收

| ID | 标准 |
|----|------|
| E1 | 一块重物不足以关闭终点护盾 |
| E2 | 不破坏重物仓无法取得第二块重物 |
| E3 | 宽环无法直接通过窄孔 |
| E4 | 两重物缩环通过后，扩环可在同步窗口内关闭护盾 |
| E5 | 全程仅使用引力井、轨道塑形与场景破坏 |

---

## F 腔：把环立起来

### 空间

- 一块轻货物位于入口侧。
- 中央墙只有纵向窄缝：水平环占宽过大，竖直环可通过。
- 缝后侧向压板打开通往 G 的门。

### 教学

货物入轨 → 缩环 → Shift + 滚轮把轨道旋转 90° → 穿过纵缝 → 放平轨道刮压板。

### 验收

| ID | 标准 |
|----|------|
| F1 | Shift + 滚轮能以可预测步进旋转轨道平面 |
| F2 | 自动轨迹确实达到 90°，货物中心通过纵缝 |
| F3 | 缝后可恢复水平环并触发侧向压板 |
| F4 | R 后货物、压板和门恢复，不软锁 |

---

## G 腔：脉冲窗口与易碎货物

### 空间

- 青色易碎货物位于入口。
- 红色抑制场按“亮 1.5 秒 / 暗 2 秒”循环。
- 场后压板打开通往 H 的门。

### 教学

稳定捕获易碎货物 → 观察场熄灭 → 在开放窗口内平稳拖过 → 刮压板；高速甩墙会损坏货物。

### 验收

| ID | 标准 |
|----|------|
| G1 | 脉冲场亮起时阻断井路径，熄灭时允许通过 |
| G2 | 货物在稳定轨道运输中保持完整 |
| G3 | 高冲击会使易碎货物失效并在重置时恢复 |
| G4 | 一次开放窗口足够完成合理速度的穿越 |

---

## H 腔：轨道编舞终考

### 空间

- 入口同时给出重物和青色易碎诱饵。
- 第一段为纵向窄缝，第二段为常亮抑制场。
- 场后只有重物能驱动质量接收器。

### 教学

选择重物 → 缩环并立环 → 穿过纵缝 → 在常亮场前瞄准 → 松手越场抛入质量接收器。易碎诱饵不适合最后的高速撞击。

### 验收

| ID | 标准 |
|----|------|
| H1 | 轻 / 易碎诱饵不能替代重物完成最终接收 |
| H2 | 重物轨道达到 90° 并通过纵缝 |
| H3 | 引力井本身不能越过第二段常亮抑制场 |
| H4 | 脱环重物可越场并启动质量接收器 |
| H5 | 一条解法连续使用选择、缩环、立环、运输与抛射 |

---

## I 腔：喂饱即钥匙（坍缩门）

### 空间

- 中央一簇散落轻质量（一枚在心 + 一圈五枚）。
- 紫色坍缩门守着通往 J 的出口，门只在附近出现黑洞时开启。
- 前八腔一直教"别喂太多"，这里把规则翻面。

### 教学

放井 → 把整簇质量吸入 → **故意持续喂养**直到井坍缩成黑洞 → 触发坍缩门。

### 验收

| ID | 标准 |
|----|------|
| I1 | 质量不足时门保持关闭 |
| I2 | 井吞入足量质量、进入黑洞阶段后，附近坍缩门开启 |
| I3 | 坍缩门开启后联动的滑门打开 |
| I4 | R 后门与散落质量恢复，不软锁 |

---

## J 腔：场是工作台（反向收容场）

### 空间

- 青色反向收容场把井锁在一个小格内。
- 格内有一簇货物；格外走廊尽头是接收台。
- 与 D 腔的红场相反：这里井**只能**待在场内。

### 教学

在格内放井 → 货物入轨 → 尝试把井拖出格外被挡（井只能在格内）→ 瞄准走廊松手，把货物甩出格外落到接收台。

### 验收

| ID | 标准 |
|----|------|
| J1 | 井可在反向收容格内生成并塑形 |
| J2 | 任何把井拖出格边界的尝试都被挡回 |
| J3 | 脱环货物可越过格边界并触发走廊接收台 |
| J4 | 井全程未离开格（wellMaxX 受限），仍完成过关 |

---

## K 腔：双动词终考

### 空间

- 一个较大的反向收容格，内含一簇散落质量。
- 格外守着坍缩门与联动滑门。
- 同时考察反向收容 + 坍缩门两条"翻面"规则。

### 教学

被困在收容格内 → 把散落质量聚拢吸入 → 养成黑洞触发格外坍缩门 → 出口打开。

### 验收

| ID | 标准 |
|----|------|
| K1 | 井被收容格锁在格内，拖不出去 |
| K2 | 在格内聚足质量、进入黑洞阶段可触发坍缩门 |
| K3 | 坍缩门开启后联动滑门打开 |
| K4 | 井全程未离开格，仍完成过关 |

---

## L 腔：切向弹弓（环即发射台）

### 空间

- 中央一块轻货物；井起在中央。
- 走廊尽头没有可用接收器——朝准星丢只会白白飞出去。
- 左右两侧各有一面长条侧墙接收器，任一被击中即开门。

### 教学

轻货物入轨 → 缩环成紧快的环 → **切向释放**：不朝准星丢，而是让环的自转把货物沿切线甩向侧墙。方向由松手相位决定。

### 验收

| ID | 标准 |
|----|------|
| L1 | 朝准星（沿走廊）丢，两侧接收器都不会触发 |
| L2 | 切向释放把货物沿轨道切线甩出，横向位移明显 |
| L3 | 击中任一侧墙接收器即开门 |
| L4 | R 后货物、接收器、门恢复，不软锁 |

---

## M 腔：级联坍缩喷发

### 空间

- 中央一大堆可吸质量；井起在堆中。
- 堆心有一个"过载器"：井吃到设定质量即强制引爆。
- 四周一圈接收器（六边形），全部联动同一扇门。

### 教学

把整堆质量吸入 → 质量攀升 → 过载器引爆井 → 质量**径向四散喷发** → 一次同时点亮一圈接收器（≥3 个），开门。任何单次瞄准都做不到。

### 验收

| ID | 标准 |
|----|------|
| M1 | 井吃到过载阈值后被强制引爆（自身消失） |
| M2 | 引爆为径向喷发，质量向四周飞散 |
| M3 | 一次喷发同时触发 ≥3 个环形接收器 |
| M4 | 门开启；R 后质量堆、接收器、门恢复，不软锁 |
