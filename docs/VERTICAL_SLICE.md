# Demo 垂直切片 — 试验腔

只制作 **一个连续的「试验腔」关卡**，分成三个区域。无菜单、无剧情；启动即进入 A 区。目标流程时长 **5–8 分钟**，每一分钟展示核心机制的不同维度。

```
[ A 区：基础操作 ] → [ B 区：攻击与连锁 ] → [ C 区：质量与解谜 ] → 出口
```

## 全局约束

- 单一关卡、线性推进（门/护盾分隔区域）。
- 不需要存档；死亡可重生在当前区入口（实现阶段再定，Demo 可用简单 Checkpoint）。
- 记忆颗粒摆放：A 区入口附近完成第 5 秒视觉钩子；A→B 过渡或 B 区入口布置「杂物堆」完成第 30 秒哇时刻；B→C 衔接重型敌人与爆炸桶完成第 2 分钟深度。

---

## A 区：基础操作

### 空间与道具

- 白色房间；地上散落彩色方块（`Simulate Physics`）。
- 墙上巨大红色按钮；旁边有一扇关闭的门通往 B 区。

### 教学目标

玩家自然学会：瞄准 → 生成奇点 → 吸住方块 → 松手砸向按钮。

### 验收标准

| ID | 标准 |
|----|------|
| A1 | 右键按住可在瞄准点生成奇点，周围方块可见地向中心滑动 |
| A2 | 松开右键后，被吸方块被甩出并带有明显动量 |
| A3 | 用物理方块撞击红色按钮后，通往 B 区的门打开 |
| A4 | 无法用「空手」或非物理手段直接开门（必须砸中按钮） |
| A5 | 无文字教程 UI；仅靠场景可读性引导（按钮颜色、门缝光等） |

---

## B 区：攻击与连锁

### 空间与道具

- 缓慢移动的几何体敌人（靠近玩家造成接触伤害）。
- 金属管道、箱子、玻璃窗等可破坏/可吸场景碎片。
- **杂物堆**：数十个小立方体，用于第 30 秒「哇时刻」。

### 教学目标

- 清光敌人通关。
- 发现：直接砸方块效率低；把敌人吸入再抛出撞墙/撞其他敌人可一击必杀。
- 至少一次「多敌人同吸、松手互撞全灭」的空间机会。

### 验收标准

| ID | 标准 |
|----|------|
| B1 | 敌人会走向玩家，接触造成伤害；可被奇点吸入并物理抛射 |
| B2 | 敌人被高速抛射撞墙或互撞时死亡（或等同「击杀」） |
| B3 | 杂物堆在首次开启奇点时产生明显悬空旋转 + 崩塌炸开连锁 |
| B4 | 清光本区全部敌人后，通往 C 区的门打开 |
| B5 | 关卡布局允许 ≥2 个敌人同时进入同一奇点吸引范围 |

---

## C 区：质量与解谜

### 空间与道具

- 无法被小物体伤害的重型敌人。
- 沉重球体、红色爆炸桶。
- 出口被能量护盾挡住；左右各一个开关，需 **同时** 被高重量物体砸中才能关闭护盾。

### 教学目标

- 「吸爆炸桶砸重型敌人」建立质量/伤害梯度直觉。
- 在一次奇点持续时间内吸起两个重物，并用甩动手法分别命中左右开关——展示操作上限。

### 验收标准

| ID | 标准 |
|----|------|
| C1 | 小碎片撞击无法对重型敌人造成有效伤害；爆炸桶或重球可以 |
| C2 | 爆炸桶被高速撞击或命中重型敌人后引爆并造成范围伤害 |
| C3 | 护盾在左右开关 **同时处于激活窗口** 时才关闭（单次奇点双砸是设计意图；实现可用短时间双命中窗口） |
| C4 | 护盾关闭后出口可通行，Demo 结束（可简单显示「试验完成」或淡出） |
| C5 | 玩家仅靠奇点机制即可完成，无传统武器后备方案 |

---

## Demo 体验时间线（参考）

| 时间 | 期望体验 |
|------|----------|
| 0–5s | 视觉钩子：奇点扭曲 + 物体颤抖吸入 |
| ~30s | 杂物堆哇时刻 |
| ~2min | 爆炸桶 + 重型敌人 + 甩动射开关 |
| 5–8min | 通过 C 区出口，结束 |

## 非目标（本 Demo 不做）

- 主菜单、设置、存档、剧情对话、多关卡选择  
- 复杂敌人状态机、技能树、武器升级  
- 联机与回放系统
